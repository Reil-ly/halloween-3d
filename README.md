# Лабораторная №6 — Пробуждение древнего дракона

Клип на 8 секунд с движением крыльев через armature. Рабочая страница — index.html; ресурс — assets/dragon_awakening.glb.
Запуск: python -m http.server 8006 --bind 127.0.0.1
Адрес: http://127.0.0.1:8006
Нужен интернет для загрузки model-viewer с CDN.

Три точки привязаны к анимируемой поверхности через data-surface. При замене геометрии привязки необходимо пересчитать.
Отчёт и сцена dragon_awakening.blend находятся на уровень выше. Предыдущая версия сохранена в backup_before_wing_site.
Особенности плечевых деформаций одобрены пользователем; материалы не изменялись. Смартфон и AR не тестировались. Сайт не опубликован.
